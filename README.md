# VR Nuclear Disaster Response – Chernobyl Simulation
# Overview

This is an interactive VR application simulating a nuclear disaster scenario inspired by the Chernobyl explosion. Users can experience the challenges faced during such catastrophic events and learn critical mitigation measures in a safe, immersive environment.

# Objective

Raise awareness about nuclear safety and disaster preparedness.

Provide a safe VR environment for emergency response training.

Demonstrate struggles encountered during nuclear disasters and effective response strategies.

# Features

Immersive VR Environment: Built with Unity, OpenXR, and Oculus SDK.

Disaster Simulation: Recreates immediate aftermath of nuclear explosions, including radiation hazards and structural damage.

Emergency Response Challenges: Evacuation, radiation detection, resource management.

Remediation Measures: Decontamination, medical intervention, containment, and long-term rehabilitation.

Interactive Experience: Real-time decision-making and VR interactions.

# Technologies Used

Unity 3D – Engine for VR world creation.

C# – Scripting interactions and events.

OpenXR & Oculus SDK – VR hardware integration.

VR Physics & Controls – Realistic virtual object handling.

# Learning Outcomes

Understand challenges during the Chernobyl disaster.

Explore effective mitigation strategies.

Gain practical experience in developing immersive VR training applications.



# Contributions

Developed as part of Smart India Hackathon, demonstrating the value of VR-based disaster training tools.
